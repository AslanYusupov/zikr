# zikr

Счётчик поминания. Вход по почте и паролю, статистика и рейтинг пишутся в Postgres, а не только в закладку телефона.

## Свой адрес на Vercel

Секреты в репозиторий не входят. Их нужно задать в Vercel → Settings → Environment Variables:

| Переменная | Зачем |
|---|---|
| `DATABASE_URL` | Строка подключения Postgres. Подойдёт Supabase: Project Settings → Database → URI (режим pooler). |
| `BETTER_AUTH_SECRET` | Случайная строка от 32 символов. Подпись сессий. |
| `BETTER_AUTH_URL` | Адрес сайта, например `https://имя.vercel.app` |
| `VITE_AUTH_ENABLED` | `true` |

После первого деплоя сборка сама создаёт таблицы (`npm run build` запускает миграции).

На телефоне: настройки → аккаунт → регистрация почтой и паролем. Удаление иконки с экрана не стирает счёт, если войти той же почтой.

Рейтинг и «кто сейчас поминает» тоже лежат в этой базе. Без `DATABASE_URL` сервер их не удержит.
